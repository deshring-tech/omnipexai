What changed, and did it matter?

Pick the config from before your change and the one from after, then hit Analyze. OmniPex works out which components are affected, re-runs only the evaluations at risk, and separates real quality changes from random LLM noise.

Which change broke it?

When one commit changes several things, OmniPex isolates each change on its own, re-runs the affected metric, and names the one responsible — including when a second change was quietly masking the damage.
